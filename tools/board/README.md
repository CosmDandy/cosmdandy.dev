# Плата: как это устроено и как править

Схема сервера собирается из независимых узлов. Узел — один файл в `blocks/`.
Он рисует себя и ничего не знает о соседях, поэтому два узла можно править
одновременно: конфликта не будет ни в git, ни на картинке.

```
build.py            порядок сборки, проверка границ, отчёт, вставка в index.html
diff_ref.py         сверка сборки с эталоном побайтово
audit_text.py       наложения подписей и корпусов
board/
  geom.py           ЕДИНСТВЕННОЕ место, где написано, что где лежит
  canvas.py         холст, регистр занятых мест, share между блоками
  palette.py        цвета: текстолит, серебро, свечение ламп
  ink.py            краска: подписи, шелкография, выноски, зоны захвата
  lamps.py          индикация: fault, act_led, ореолы
  metal.py          площадки, фаски, гребёнки, шильдики, перфорация
  ports.py          гнёзда RJ45 и SFP+
  revision.py       партномера: хэш последнего коммита файла узла
  blocks/           24 узла + крышка
```

## Как править узел

Открыть его файл, поменять, запустить `tools/sync.sh`. Всё.

```python
BOUNDS = (178, 6, 274, 832)      # свой прямоугольник, необязательно

def render(cv):
    cv.add('<g class="pick fan">…</g>')     # положить фрагмент
    cv.busy(x, y, w, h)                     # занять место
    if cv.put(x, y, w, h):                  # занять, если свободно
        ...
```

Координаты берутся из `geom`, а не пишутся числами: `from board.geom import
X_FAN, FAN_W`. Цвет лампы — из `lamps`, а не свой: индикация обязана
выглядеть одинаково на диске, вентиляторе и памяти, иначе схема рассыпается
на лоскуты.

## Три вещи, которые нельзя делать в одиночку

**Порядок** (`build.py:ORDER`) — он же порядок слоёв, он же очередь на место:
кто первым занял прямоугольник, того и место. Рассыпуха идёт поздно, потому
что садится в остаток. Менять этот список — осознанное решение.

**Геометрия** (`geom.py`) — общий стол. Двигать чужой узел отсюда значит
двигать и его содержимое.

**Палитра и лампы** — то же самое: их правят редко и целиком.

## Что проверяет сборка

- **Границы.** Если узел объявил `BOUNDS`, сборка падает с его именем, когда
  он из них вышел. Это и есть гарантия, что двое не налезут друг на друга:
  ошибку находит скрипт, а не глаз.
- **Что не поместилось.** Место на плате кончается; `place()` докладывает,
  какая деталь не встала. Молчаливая потеря деталей случалась трижды.
- **Наложения подписей** — `audit_text.py`, гоняется из `sync.sh`.
- **Неизменность вывода** — `diff_ref.py <каталог с эталоном>`. Перед любым
  рефакторингом: сохранить `board-v17*.svg.part` в сторону, порезать, сверить.
  Расходиться разрешено только хэшам коммитов и номеру ревизии.

## Связи между узлами

Их две, и обе явные.

**Данные — через `canvas.share`.** Разводка публикует свои узлы, переходные
отверстия и рассыпуха ставятся по ним:

```python
cv.share['knots'] = knots        # pcb_traces
kx, ky = cv.share['knots'][i]    # pcb_vias, pcb_scatter
```

**Место — через регистр занятых мест.** Кто раньше в `ORDER`, тот и занял.

## Партномера

У каждого узла на схеме свой P/N — это хэш последнего коммита его файла.
`stamp()` определяет файл по стеку вызова, поэтому в блоке достаточно:

```python
cv.add(stamp(X_FAN + 6, 14, 'вентиляторы'))
```

Третий аргумент ни на что не влияет и остаётся для читаемости. Пока узел не
трогали, его партномер не меняется — и клик по нему открывает тот коммит,
который его последним менял.
